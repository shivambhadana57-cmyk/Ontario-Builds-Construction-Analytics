# Power BI Folder

This folder contains the Power BI dashboard developed for the Ontario Builds Construction Analytics project.

## Main File

`Ontario_Builds_Dashboard.pbix`

## Tools Used

- Microsoft Power BI Desktop
- Power Query
- DAX

## Dashboard Pages

**Page 1 – Project Overview**
Contains two cards and eight charts presenting project counts, status, categories, funding indicators, regional distribution, estimated budgets and target completion information.

**Page 2 – Filters**
Contains Category and Project Status slicers.

The dashboard provides descriptive analysis of the selected public infrastructure dataset.
