# Data Folder

This folder contains the original public dataset used in the Ontario Builds Construction Analytics project.

## Dataset

- File: `ontbuilds-all-20260612.csv`
- Publisher: Government of Ontario, Canada
- Format: CSV

## Source

https://open.canada.ca/data/en/dataset/aefd72d3-f67c-44ed-b017-b74e7ecd9258

The dataset contains infrastructure project details, including project names, categories, status, estimated budgets, funding indicators and geographical information.

The original dataset is retained separately from the Power BI report. Data preparation and transformation were performed in Power Query.
